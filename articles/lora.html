LoRA: низкоранговая адаптация больших языковых моделей

Edward Hu et al. "LoRA: Low-Rank Adaptation of Large Language Models", arXiv:2106.09685v2, 2021.

Исходная работа: Edward Hu et al. "LoRA: Low-Rank Adaptation of Large Language Models", arXiv:2106.09685v2, 2021.

Введение

Современный подход в обработке естественного языка (Natural Language Processing, NLP) базируется на предварительном обучении больших языковых моделей (Large Language Models, LLM) на общих данных с последующей адаптацией к конкретным задачам или доменам. Однако с ростом размеров моделей, например GPT-3 с 175 миллиардами параметров, полная дообучаемость (fine-tuning) становится крайне ресурсоёмкой и дорогостоящей.

В статье предлагается метод Low-Rank Adaptation (LoRA) — низкоранговая адаптация, которая замораживает исходные веса модели и вводит обучаемые матрицы низкого ранга в каждый слой архитектуры трансформера. Это значительно уменьшает количество параметров, требующих обновления при адаптации к задачам.

Основная идея LoRA

LoRA предлагает представить обновление весов слоя в виде произведения двух низкоранговых матриц:

\[ W = W_0 + \Delta W = W_0 + BA, \]

где \(W_0\) — замороженные предварительно обученные веса, \(B \in \mathbb{R}^{d \times r}\), \(A \in \mathbb{R}^{r \times k}\) — обучаемые матрицы с рангом \(r \ll \min(d,k)\). Обучение происходит только для матриц \(A\) и \(B\), что существенно снижает число параметров.

Инициализация: \(A\) случайно с нормальным распределением, \(B\) — нулевой, чтобы в начале \(\Delta W = 0\).

Преимущества:

  • Значительное сокращение числа обучаемых параметров (примерно в 10 000 раз для GPT-3 175B).
  • Снижение требований к памяти GPU (примерно в 3 раза).
  • Отсутствие дополнительной задержки при инференсе, так как обучаемые матрицы можно объединить с основными весами.
  • Возможность быстрой смены задач путем замены только матриц \(A\) и \(B\), без необходимости хранить полные веса модели для каждой задачи.

Проблематика существующих методов

Существующие методы параметрически эффективной адаптации включают:

  • Адаптеры (Adapters) — вставка дополнительных слоев между слоями трансформера. Недостаток: увеличение задержки при инференсе, особенно при малых размерах батча и коротких последовательностях.
  • Оптимизация префиксов (Prefix-tuning) — обучение специальных токенов-префиксов, влияющих на активации модели. Недостаток: ограничение длины входной последовательности и нестабильность оптимизации.

LoRA избегает этих проблем, сохраняя высокую производительность и эффективность.

Применение LoRA к трансформеру

В трансформере есть четыре матрицы весов в модуле самовнимания (self-attention): \(W_q, W_k, W_v, W_o\) и две в MLP-модуле. В экспериментах LoRA применяется преимущественно к матрицам \(W_q\) и \(W_v\), что обеспечивает баланс между эффективностью и производительностью.

Экспериментальные результаты

### Используемые датасеты и benchmarks

  • GLUE — набор задач для оценки понимания естественного языка.
  • WikiSQL — генерация SQL-запросов из естественного языка.
  • SAMSum — суммаризация диалогов.
  • E2E NLG Challenge, WebNLG, DART — задачи генерации текста из структурированных данных.

### Основные результаты

  • LoRA достигает качества, сравнимого или превосходящего полное дообучение на RoBERTa, DeBERTa, GPT-2 и GPT-3.
  • При этом количество обучаемых параметров сокращается на несколько порядков.
  • LoRA показывает лучшую масштабируемость с увеличением числа параметров по сравнению с адаптерами и prefix-tuning.
  • В условиях ограниченного объёма данных LoRA демонстрирует высокую эффективность, превосходя prefix-тюнинг.

Анализ низкоранговых обновлений

  • Обновления весов \(\Delta W\) действительно имеют низкий ранг (часто достаточно \(r=1\) или \(r=2\)).
  • Субпространства, образованные обновлениями с разными рангами и разными инициализациями, сильно пересекаются по главным сингулярным векторам.
  • Обновления \(\Delta W\) коррелируют с исходными весами \(W\), усиливая важные, но не доминирующие направления.
  • Амплитуда усиления таких направлений может быть значительной (в 20 раз для \(r=4\)).

Заключение

LoRA — эффективный метод адаптации больших языковых моделей, позволяющий:

  • Сохранять качество модели при значительном сокращении числа обучаемых параметров.
  • Исключать дополнительные задержки при инференсе.
  • Облегчать хранение и переключение между задачами.

Метод применим не только к трансформерам, но и к другим нейросетям с плотными слоями.

Глоссарий

  • Fine-tuning (Дообучение) — процесс дополнительного обучения предварительно обученной модели на конкретной задаче.
  • Low-Rank Adaptation (LoRA) (Низкоранговая адаптация) — метод представления обновлений весов в виде произведения двух матриц низкого ранга.
  • Transformer (Трансформер) — архитектура нейросети, основанная на механизме внимания (attention), широко используемая в NLP.
  • Self-attention (Самовнимание) — механизм, позволяющий модели учитывать взаимосвязи между элементами последовательности.
  • Adapter (Адаптер) — дополнительный небольшой слой, вставляемый в архитектуру модели для адаптации к новым задачам.
  • Prefix-tuning (Префикс-тюнинг) — метод адаптации, при котором обучаются специальные токены-префиксы, влияющие на поведение модели.
  • GLUE (General Language Understanding Evaluation) — набор задач для оценки качества моделей понимания языка.
  • WikiSQL — датасет для задачи генерации SQL-запросов из естественного языка.
  • SAMSum — датасет для задачи суммаризации диалогов.
  • E2E NLG Challenge, WebNLG, DART — датасеты для задач генерации текста из структурированных данных.
  • Singular Value Decomposition (SVD) (Сингулярное разложение) — метод факторизации матриц, используемый для анализа ранга и структуры матриц.
  • Frobenius norm (Норма Фробениуса) — мера размера матрицы, используемая для оценки величины обновлений весов.
